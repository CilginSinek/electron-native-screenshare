# Security Policy

## Supported Versions

The following versions of `electron-native-screenshare` are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < v1.0.0| :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, **PLEASE DO NOT CREATE A PUBLIC ISSUE**.

Instead, please take one of the following actions:
1. Use the "Security" tab on the GitHub repository to privately report a vulnerability.
2. Contact the maintainer directly through their GitHub profile or associated email address.

We take all security issues seriously and will respond to reports as quickly as possible. Please provide a clear explanation of the vulnerability and steps to reproduce it.
